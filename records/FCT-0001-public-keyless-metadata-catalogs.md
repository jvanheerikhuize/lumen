---

## Statement
Publicly accessible metadata catalogs expose comprehensive movie, television series, and anime catalogs—including genre classifications, release years, community ratings, synopses, artwork, season/episode trees, and daily broadcast schedules—without requiring user registration or mandatory API credentials.
