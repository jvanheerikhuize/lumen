# SPC-0002 · Embedded and external subtitle pipeline

Tier: **feature** · Readiness: **100%**

Builds on: SPC-0001

Layers multi-language subtitle support onto the playback skeleton: extracting embedded text subtitle tracks from media containers and querying external subtitle providers by canonical IMDb/season/episode identifiers, normalized to WebVTT with live `±0.5s` synchronization adjustment.

## Requirements

### REQ-0006 · Embedded and external subtitle extraction, WebVTT normalization, and live sync offset (active)

The system MUST provide both embedded container subtitles and external multi-language subtitles in WebVTT format with live synchronization controls:
1. **Embedded subtitles**: Extract text-based subtitle streams (`subrip`, `srt`, `ass`, `ssa`, `webvtt`, `mov_text`) detected during media inspection directly to WebVTT via stream index, cached in memory per input + track index.
2. **External subtitles**: Query external subtitle providers by canonical IMDb ID (plus `season` and `episode` for series/anime), filter by user-selected language codes (defaulting to English, Spanish, French, German, Dutch, Portuguese, Italian), and convert SubRip (`SRT`) responses (`max 2 MB`) to valid `WEBVTT` cues.
3. **Timeline & sync adjustment**: When remuxing/transcoding starts at a seek offset (`start > 0`) or when the user adjusts subtitle delay (`G` / `H` in `0.5s` increments), shift all parsed cue start/end timestamps accordingly without refetching from the network.

**REQ-0006#1**

```gherkin
Given an MKV stream with an embedded English SubRip track and external Dutch subtitles from OpenSubtitles
When the player opens the subtitle menu and the user presses `H` (`+0.5s`)
Then both embedded and external tracks appear as selectable WebVTT tracks and all cue timestamps shift forward by 0.5 seconds immediately
```

Because:
- FCT-0002 (active): Anime catalogs index by seasonal entry IDs while stream and subtitle providers index by canonical Kitsu or IMDb IDs
- FCT-0003 (active): Standard playback clients decode only a subset of video and audio codecs natively

## Directory Layout

- `cmd/lumen/main.go` — Single-binary entrypoint (`PORT`, `LUMEN_DATA_DIR`).
- `internal/server/` — HTTP handlers for `/api/health`, `/api/media/*` (including `?kids=1` filtering in `kids.go`), `/api/stream`, `/api/stream/status`, `/api/subtitles/*`, `/api/live/*`, and `/api/state`.
- `internal/metadata/` — Keyless Cinemeta, AniList GraphQL, `Fribb/anime-lists` cross-reference, and optional TMDB client with genre ID mapping.
- `internal/scrapers/` — Concurrent Torrentio, TPB (`apibay.org`), YTS, Nyaa/AnimeTosho, and custom Stremio addon scrapers with source ranking.
- `internal/streaming/` — `anacrolix/torrent` engine, piece prioritization, `downloadedRanges` telemetry, and `ffmpeg`/`ffprobe` remux/transcode pipeline.
- `internal/live/` — Free-TV/IPTV M3U parser with ISO country attribution & `Kids` classification, fallback broadcaster list, and HLS manifest/segment CORS proxy.
- `internal/subtitles/` — OpenSubtitles REST v3 lookup and SRT-to-WebVTT converter.
- `internal/state/` — Embedded SQLite per-member household state store (`profile_watch_progress`, `profile_favorite_channels`, `household_profiles`).
- `internal/personalization/` — Genre affinity scoring and row personalization.
- `internal/netguard/` — SSRF and DNS-rebinding socket-level dialer guard.
- `src/` — React 19 + TypeScript SPA source (`Navbar`, `HeroBanner`, `MediaCarousel`, `PosterCard`, `CatalogBrowser`, `MediaDetailModal`, `LiveChannelsGrid`, `VideoPlayerModal`, `SettingsModal`, `ProfileManagerModal`, `SelectDropdown`, `kidsFilter.ts`, `watchProgress.ts`).
- `web/` — `//go:embed all:dist` package embedding the production Vite bundle.
